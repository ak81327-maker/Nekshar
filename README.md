- `robots.txt` — Search engine instructions
- `sitemap.xml` — Website sitemap

## Important Payment Note

The current payment button is a demo payment screen.

Before accepting real customer payments, connect a real payment gateway such as Razorpay using a secure server-side integration. Do not put secret API keys inside `index.html` or `script.js`.
